01 — The app

The Itinerists, running right here

Angular 19 and TypeScript on a real-time Firestore backend: authentication, security rules, invite-and-join trip sharing, 20+ lazy-loaded feature pages, and an emulator test suite that proves the rules hold.

It started as a single-trip prototype. I re-architected it into a multi-trip platform and wrote the migrations that carried live user data across without breaking a single itinerary. It is still in active development — a small group of travellers use it and tell me what to fix next.

The phone runs a demo build seeded with a sample trip, so there is nothing to sign in to. Add, edit and reorder whatever you like; it all lives only in this session.
